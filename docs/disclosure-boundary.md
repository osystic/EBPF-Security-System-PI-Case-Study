# Disclosure Boundary

This repository is intentionally safe for public portfolio use.

## Not included

- client name or identifying business information
- email addresses, phone numbers, physical addresses, social handles, or messaging IDs
- private repository URLs
- credentials, secrets, keys, or tokens
- production IPs, endpoints, hostnames, or infrastructure topology
- contract IDs, payment details, milestone values, invoices, or private marketplace messages
- client-delivery source code
- operational policy/configuration files
- unverified performance, ROI, latency, or detection-rate claims

## Repository relationship

This public repository is a **separate sanitized showcase**. It is not a mirror, fork, or source-code export of the confidential delivery repository.
